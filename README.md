## 📖 Sobre o Projeto

O **NTH (Neon Threat Hunters)** é uma suíte avançada de cibersegurança que centraliza ferramentas essenciais de reconnaissance, análise de vulnerabilidades, auditoria de credenciais e geração de relatórios de inteligência de ameaças em um único *Cyber Operations Center*.

Projetado para auditores de segurança, *pentesters* e analistas de SOC, o NTH oferece uma interface modular e intuitiva integrada a um terminal de comandos de alta performance.

---

## ⚡ Principais Módulos

A plataforma conta com os seguintes módulos operacionais integrados:

| Módulo | Descrição |
| :--- | :--- |
| 🌐 **Recon & OSINT** | Coleta de informações públicas e mapeamento de superfície de ataque. |
| 🛡️ **Port Scanner** | Varredura e identificação de portas abertas e serviços em execução no alvo. |
| ⚡ **DDoS Sim** | Simulação de ataques de negação de serviço para testes de resiliência. |
| 🔗 **Payload Gen** | Gerador de payloads customizados para testes de penetração. |
| 🕵️ **Soc Eng** | Ferramentas de suporte a testes de engenharia social. |
| 🗺️ **Net Mapper** | Mapeamento detalhado de infraestrutura de rede e topologia. |
| 🔑 **Cred Audit** | Auditoria e verificação da força de credenciais e políticas de senha. |
| 📜 **Log Analyzer** | Análise e correlação de logs para detecção de anomalias. |
| 🚀 **Injection** | Testes de injeção de código e validação de superfícies vulneráveis. |
| 📊 **Threat Report** | Geração automática de relatórios de ameaças e vulnerabilidades. |
